# Web3 Portfolio

Modern web3 portfolio landing page with wallet connectivity and interactive blockchain visualizations.

## Features

- Web3 wallet integration (MetaMask, WalletConnect, Coinbase Wallet)
- Interactive blockchain visualizations
- Responsive design with dark theme
- Docker deployment ready

## Setup

1. Open `index.html` in a browser, or use a live server.
2. Connect your web3 wallet using the interface.
3. Explore portfolio sections.

## Tech Stack

- HTML/CSS/JavaScript (no framework)
- Web3 wallet APIs
- Docker + Nginx
